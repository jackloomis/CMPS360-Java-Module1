# Store Inventory App

### Structure
- Consists of a Product class and the InventoryApp class which contains main()
- Product attributes are:
    - name
    - price
    - quantity
- InventoryApp uses an ArrayList to store Product objects
- JOptionPane utility is used to produce a GUI message containing inventory information
- StringBuilder enables combining product information and total inventory value into a single inventory string for the JOptionPane utility
- The forEach array method is used to print product information to the console as well as append it to the inventory string
