# Student Grade Calculator

### How to run the program
- Student info needs to be passed to the constructor to create a StudentGradeCalculator object
- Either modify the values provided for the student1 object or create a new StudentGradeCalculator object
- If creating a new object, format should be as follows:
    - `new StudentGradeCalculator(studentName, major, course, grade1, grade2, grade3)`
- calculateAverage() method will return the average grade and the conditional statement in main() prints a message based on pass/fail
